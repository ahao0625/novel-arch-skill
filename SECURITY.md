## 报告安全漏洞

我们非常重视安全问题。如果您发现了安全漏洞，请按照以下步骤报告：

### 如何报告

1. **请勿**在公开的 GitHub Issues 中报告安全问题
2. 发送电子邮件至：[your-email@example.com](mailto:your-email@example.com)
3. 邮件主题请使用：`[SECURITY] Novel Arch - 简短描述`

### 报告内容

请在报告中包含以下信息：

- 安全漏洞的类型和位置
- 复现问题的步骤
- 潜在影响的评估
- 建议的修复方案（如果已知）

### 响应时间

- **首次响应**：我们将在 48 小时内确认收到您的报告
- **状态更新**：我们将在 7 天内提供更详细的状态更新
- **修复计划**：我们将尽快发布安全补丁，并在适当的时候公开披露

### 致谢

我们感谢安全研究人员对项目安全的贡献。**我们计划在获得许可后，在安全更新日志中公开致谢**。

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security vulnerability, please report it using the following steps:

### How to Report

1. **Do NOT** create a public GitHub issue for security vulnerabilities
2. Send an email to: [your-email@example.com](mailto:your-email@example.com)
3. Subject line: `[SECURITY] Novel Arch - Brief Description`

### What to Include

Please include the following information in your report:

- Type and location of the security vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Suggested remediation (if known)

### Response Timeline

- **Initial Response**: We will acknowledge receipt of your report within 48 hours
- **Status Update**: We will provide a more detailed status update within 7 days
- **Fix Plan**: We will release security patches as soon as possible and disclose publicly when appropriate

### Recognition

We appreciate security researchers who contribute to the security of this project. **With your permission, we will publicly acknowledge you in our security update notes.**
