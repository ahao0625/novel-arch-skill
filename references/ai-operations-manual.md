# Novel Arch — AI 操作手册

> **这是 AI 执行时的指令手册，不是给用户看的。**
> 当用户触发 Novel Arch 技能时，AI 读取本手册并按以下操作流程执行。
> 任何 AI 平台通用。所有路径均为项目根目录的相对路径。

## 操作一：新建项目

### 触发条件
用户说：新建项目 / 开新书 / 启动新项目 / 按照架构创建 / 初始化

### 前置条件
确认：项目名、类型、卷数、目标字数、用户是否提供大纲

### 执行步骤

#### Step 1：创建目录结构

按以下结构手动创建所有目录和文件：

```
{项目名称}/
├── 01_世界设定/
│   ├── 总纲.md
│   ├── 地理与势力.md
│   ├── 规则体系.md
│   ├── 设定速查锚点.md
│   ├── 设定变更日志.md
│   └── 红线清单.md
├── 02_人物档案/
│   └── 人物档案全集.md
├── 03_故事大纲/
│   ├── 全书故事大纲.md
│   └── 第一卷·章节纲要.md（每卷一个）
├── 04_时间线/
│   └── 完整时间线.md
├── 05_伏笔与悬念/
│   └── 伏笔与揭秘体系.md
├── 06_正文内容/
│   └── 第一卷/（每卷一个目录）
│       └── 卷概述.md
├── 07_章节索引/
│   ├── 第一卷索引.md
│   └── 总索引.md
├── 08_创作日志/
│   ├── 第一卷创作日志.md
│   └── 卷内章节摘要缓存.md
├── 09_审计报告/
│   └── 第一卷/
├── 10_创作模板/
│   ├── 章节正文模板.md
│   ├── 章节纲要模板.md
│   ├── 审计报告模板.md
│   ├── 卷概述模板.md
│   └── 设定速查锚点模板.md
├── 创作工作流.md
└── 项目配置.md
```

> 题材适配：`01_世界设定` 可改为 `01_时代背景`（都市）、`01_科技与世界观`（科幻）、`01_时代与制度`（历史）、`01_故事背景`（悬疑）。

#### Step 2：判断输入类型

| 用户输入 | AI 行为 |
|:---|---:|
| 完整大纲/设定文档 | 逐段提取六类信息（世界观/角色/剧情/时间/悬念/红线），填入对应文件 |
| 几句话的创意 | 合理扩展构建骨架，AI 补充内容标注【AI 建议，请确认】 |
| 只有书名 | 创建空文件，不自作主张填充任何内容 |

#### Step 3：填充文件

每个文件严格按以下字段规范填充。**缺失的【必填】字段不得自行编造，标注【待补充】。**

**01_世界设定/总纲.md**
```
书名（必填）、类型（必填）、目标字数（必填）、核心主题（必填）
核心矛盾（必填：从大纲提取；无则【AI 推断】）
设定体系（必填：力量/科技/社会规则）
```

**01_世界设定/设定速查锚点.md**
```
主角状态（必填：姓名/等级/所在地）
当前卷（必填）/ 核心矛盾（必填）
势力关系（推荐）
活跃悬念（推荐：编号/描述/预计回收）
```

**01_世界设定/红线清单.md**
```
角色红线（推荐）、设定红线（推荐）、情节红线（推荐）
```

**01_世界设定/设定变更日志.md**
```
初始化 v1.0 行：版本/日期/变更内容/变更原因/影响范围
```

**02_人物档案/人物档案全集.md**
```
每个角色一条记录，字段：
  姓名（必填）、身份（必填）、性格（推荐）、能力（必填）、动机（必填）、关键关系（推荐）
缺失：必填留【待设定】，推荐留【待补充】
```

**03_故事大纲/全书故事大纲.md**
```
多卷结构（必填）、每卷一句话摘要（必填）、核心事件链（必填）
```

**03_故事大纲/第一卷·章节纲要.md**
```
前 10 章规划（必填：章号/标题/核心事件/字数）
第 11 章起（可选：留【待填充】）
```

**05_伏笔与悬念/伏笔与揭秘体系.md**
```
伏笔编号（必填：A/B/C 分级）、描述（必填）、预计回收卷/章（推荐）
```

**06_正文内容/第一卷/卷概述.md**
```
卷号（必填）、核心事件（必填）、主角起止状态（必填）
```

**06_正文内容/第一卷/第1章.md**
```
按操作二的规范执行（含章节元数据头部）
```

**项目配置.md**
```
书名、类型、字数、卷数（从项目信息填入）
AI 行为指令：每次创作前读设定速查锚点，写完更新日志
```

#### Step 4：自检

```
□ 每个【必填】字段是否都已非空？
□ 缺失数据是否标注了【待补充】，没有自行编造？
□ AI 推断/建议的内容是否标注了【AI 推断】/【AI 建议】？
□ 大纲中提到的每个主要角色都在人物档案中？
□ 目录结构是否完整（01~10 齐全）？
```

#### Step 5：输出报告

```
✅ 项目搭建完成

已填充：{文件清单}
待补充：{缺失字段清单}

自检结果：{通过/有警告}

下一步建议：
1. {建议}
2. {建议}
```

## 操作二：写入章节

### 触发条件
用户说：写第X章 / 继续写 / 接着写 / 写出第X章

### 前置条件
1. 确认当前卷号和章节号
2. 必读 3 个文件：
   - `01_世界设定/设定速查锚点.md`
   - `03_故事大纲/第X卷·章节纲要.md`
   - `08_创作日志/卷内章节摘要缓存.md`

### 执行步骤

#### Step 1：准备章节元数据

```yaml
---
章号: {数字}
卷: {中文数字}
时间: {故事内时间}
地点: {场景名称}
主角状态: {等级/状态}
活跃角色: {出场角色}
本章核心: {一句话，≤20字}
前情提要: {上一章末尾，1-2句}
---
```

#### Step 2：四阶段写作

```
① 深度分析 → 章节纲要中的核心冲突 + 情绪曲线
② 结构规划 → 字数分配：起10% 承40% 转35% 合15%
③ 优质撰写 → 逐段输出
④ 自我质检 → 见 Step 4
```

#### Step 3：写作规范

**字数要求：** 单章 2000-3000 字

**去 AI 痕迹管控**
```
限频词（每 3000 字 ≤ 1 次）：
  不由得、脑海中、心头一震、猛然间、缓缓、淡淡、竟然、仿佛、忽然

禁止行为：
  - 情绪形容词堆砌
  - 分析式描写（动机用行为展示）
  - 连续情绪转折（单段落 ≤ 2 次）
  - 把修炼/学习过程写进正文
  - 同一意象跨章重复
```

#### Step 4：自我质检

```
□ 字数是否在目标区间？
□ 限频词是否超标？
□ 设定与速查锚点一致？
□ 角色行为符合性格档案？
□ 章末有钩子（悬念/暗示/回收/升级）？
□ 正文中标记了伏笔引用？
```

#### Step 5：写作后维护（顺序执行）

```
1. 保存正文 → 06_正文内容/第X卷/第X章.md
2. 追加日志 → 08_创作日志/第X卷创作日志.md
   格式：| 第X章 | 日期 | 字数 | 完成度 | 小结 | 伏笔状态 |
3. 追加摘要 → 08_创作日志/卷内章节摘要缓存.md
   格式：第X章——{1-3句话}
4. 更新伏笔 → 05_伏笔与悬念/伏笔与揭秘体系.md
   埋设新增条目，回收标记状态
5. 更新索引 → 07_章节索引/第X卷索引.md
```

## 操作三：更新设定

### 触发条件
用户说：修改/添加设定 / 加个角色 / 改世界观 / 加条规则

### 执行步骤

```
1. 定位目标文件：
   | 内容 | 文件 |
   | 力量体系/规则 | 01_世界设定/规则体系.md |
   | 地理/势力 | 01_世界设定/地理与势力.md |
   | 新增/修改角色 | 02_人物档案/人物档案全集.md |
   | 新增/修改悬念 | 05_伏笔与悬念/伏笔与揭秘体系.md |
   | 新增红线 | 01_世界设定/红线清单.md |

2. 执行修改

3. 同步更新设定速查锚点（如果影响"当前状态"或"势力关系"）

4. 记录变更日志（01_世界设定/设定变更日志.md）
   格式：| v1.x | 日期 | 变更内容 | 变更原因 | 影响范围 |

自检：
□ 修改已同步到速查锚点？
□ 变更日志版本号 +1？
□ 跨目录的关联文件是否都更新了？
```

## 操作四：运行审计

### 触发条件
用户说：审计 / 检查 / 审稿 / 质量检查 / 看一下质量

### 前置条件
确认审计范围（默认最近 10 章），读取红线清单、时间线、伏笔表

### 执行步骤

#### Step 1：逐项检查

| 层级 | 检查项 | 检测方法 |
|:---:|:---|---:|
| 🔴 致命 | 设定冲突 | 对照设定文件，正文是否违反 |
| 🔴 致命 | 角色 OOC | 对照档案，言行是否符合性格 |
| 🔴 致命 | 能力超纲 | 使用了未解锁的能力？ |
| 🟡 警告 | 悬念健康 | 伏笔超 10 章未提？ |
| 🟡 警告 | 节奏检查 | 连续章节情绪曲线单一？ |
| 🟢 提示 | 格式规范 | 元数据完整？文件名规范？ |

#### Step 2：红线检测
逐条对照红线清单，有违规 → 🔴 阻断级，必须修复。

#### Step 3：输出审计报告

保存到 `09_审计报告/第X卷/第X卷审计报告（第X-X章）.md`

```
## 第X卷审计报告（第X-X章）

### 🔴 Critical（必须修复）
| 序号 | 问题 | 位置 | 修复方案 |

### 🟡 Warning（建议优化）
| 序号 | 问题 | 位置 | 建议 |

### 🟢 Info（提示项）
| 序号 | 提示 | 位置 |

### 伏笔状态
| A/B/C | 埋设中 | 已回收 | 超期 |

### 结论
- 阻断级：{有/无}
- 待修复：{清单}
```

## 操作五：关卷存档

### 触发条件
用户说：卷结束 / 关卷 / 完成本卷 / 本卷写完了

### 执行步骤

```
1. 生成设定快照 → 01_世界设定/设定快照_第X卷.md
   内容：主角状态 / 世界观状态 / 已完成事件 / 活跃伏笔 / 下卷待办

2. 刷新速查锚点 → 01_世界设定/设定速查锚点.md
   更新"当前卷"为下一卷，更新主角状态

3. 完善卷概述 → 06_正文内容/第X卷/卷概述.md
   补充：总字数、创作周期、本卷总结

4. 更新总索引 → 07_章节索引/总索引.md
   追加：本卷字数、章节数

自检：
□ 快照已生成？
□ 速查锚点的"当前卷"已更新？
□ 卷概述补充了总结？
□ 变更日志是否有遗漏？
```

## 通用规则

### 内容标注规则

| 标注 | 含义 | 使用场景 |
|:---|:---|---:|
| 【待补充】 | 用户后续自行补充 | 必填字段无数据 |
| 【待设定】 | 需在开写前决定 | 核心设定无数据 |
| 【AI 推断】 | 基于现有信息合理推断 | 可推导的必填字段 |
| 【AI 建议，请确认】 | AI 扩展内容 | 用户只给创意骨架 |

### 文件操作规则

```
- 正文文件名：第X章.md（不加书名前缀）
- 设定文件名：不加书名前缀
- 不删除已有文件，只追加或编辑
- 编辑前先读当前内容，确认修改范围
```

### 审计触发节点

```
- 每完成 10 章 → 报告用户是否需要审计
- 卷结束时 → 自动触发关卷
- 用户主动要求 → 随时审计
```
